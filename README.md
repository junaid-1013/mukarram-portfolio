# Mukarram Shafqat Portfolio

A Next.js portfolio featuring Mukarram's UI/UX designs, live websites, videography, experience, and education.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

- Edit project links, skills, education, and experience in `src/config/constants.tsx`.
- Edit the introduction and contact details in `src/components/home/CTA.tsx`.
- The four locally hosted MP4s live in `public/videos/`.
- Experience verification PDFs live in `public/certificates/` and are linked from their corresponding experience entries.
- Mukarram's resume lives in `public/Mukarram Shafqat Resume.pdf`.

The UI/UX and website cards currently use typographic covers. Replace these with actual project screenshots when available.
